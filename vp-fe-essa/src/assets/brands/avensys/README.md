# Avensys Brand Assets

## Required Assets

Please add the following Avensys brand assets to this folder:

1. **logo.svg** - Main Avensys logo (for header/navbar)
2. **logo2.svg** - Compact Avensys logo (for sidebar)
3. **logo3.svg** - Avensys logo for authentication pages
4. **hero-image.svg** - Hero/banner image for auth pages
5. **thumbnail.png** - Video thumbnail (800x450px recommended)
6. **sidebar-background.svg** - Background image for sidebar

## Temporary Placeholders

Currently, placeholder assets are being used. Replace them with actual Avensys brand assets.

## Asset Specifications

- **Format**: SVG preferred for logos and graphics
- **Colors**: Use Avensys brand colors (update in brandConfig.js)
- **Size**: Ensure logos are properly sized for their context
- **Quality**: Use high-resolution assets for best display

## Configuration

After adding assets, update the brand configuration in:
`src/config/brandConfig.js`

Update social media links, website URLs, and other brand-specific information.
